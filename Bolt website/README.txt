--------------------------------------------------
HOW TO VIEW THE WEBSITE
--------------------------------------------------

Option 1 — Just double-click:
   1. Open this folder.
   2. Double-click "index.html".
   3. It will open in your web browser. Done!

Option 2 — Using VS Code with Live Server (recommended):
   1. Open VS Code.
   2. Go to File > Open Folder.
   3. Select the "Hannah main Claude website" folder.
   4. Right-click on "index.html" in the file list.
   5. Click "Open with Live Server".
   6. Your browser will open the website automatically.

--------------------------------------------------
HOW TO CREATE A ZIP FILE TO SEND TO YOUR CUSTOMER
--------------------------------------------------

ON WINDOWS:
   1. Open this folder in File Explorer.
   2. Go UP one level so you can see the folder
      called "Hannah main Claude website".
   3. Right-click on the "Hannah main Claude website"
      folder.
   4. Click "Send to" > "Compressed (zipped) folder".
   5. A new file called "Hannah main Claude website.zip"
      will appear next to the folder.
   6. That ZIP file is what you send to your customer!

ON MAC:
   1. Open Finder and go to where this folder is saved.
   2. Right-click (or Control-click) on the
      "Hannah main Claude website" folder.
   3. Click "Compress 'Hannah main Claude website'".
   4. A file called "Hannah main Claude website.zip"
      will appear.
   5. That ZIP file is what you send to your customer!

--------------------------------------------------
WHAT THE CUSTOMER NEEDS TO DO
--------------------------------------------------

When your customer receives the ZIP file:
   1. They double-click it to unzip/extract it.
   2. They open the extracted folder.
   3. They double-click "index.html".
   4. The website opens in their browser. Done!

No internet connection is required to view the
website (all images are included in the folder).
The only thing that needs internet is the Google
Fonts used for the premium typography.
